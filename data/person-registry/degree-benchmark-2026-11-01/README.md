# `degree` channel benchmark (2026-11-01)

50 ties drawn at random (seed 20261101) from the 294 that registry v14 anchors on the new `degree`
channel alone (an ORCID education entry naming the doctorate at the AHA school, ending within a year of
the AHA year). An agent checked each against public sources (`verdicts.json`).

- **50 same, 0 different, 0 unclear.**
- About 20 are confirmed by documents independent of the ORCID record (faculty pages, repository
  records, dissertation databases, the Wellcome catalogue). The other ~30 rest on the ORCID entry plus
  the fit of the person's listed works and field with the dissertation title, which is weaker: it
  partly restates the rule.
- Namesake risks checked: Michael Kelly, Heather Green, Jason M. Kelly, Michael Becker, Robert H. Jackson
  (Berkeley PhD given as 1988 elsewhere, AHA 1989: same person) and Benjamin Reilly. None was a different
  person.

Accepted on 20 independent confirmations with no contradiction. Re-benchmark if the channel's
definition changes.
